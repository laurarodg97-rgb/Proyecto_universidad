# README de procedencia

Una seccion por referencia clasificada como **Utilizable** en el experimento.
El documento original no se modifica: este archivo solo responde de donde sale cada referencia.

**Distribución del corpus:** los permisos de redistribución de los diez PDF no están confirmados de manera individual; por esa razón no se deben publicar. Git excluye los archivos PDF. El manifiesto [`../corpus/incluido/README.md`](../corpus/incluido/README.md) registra, para cada PDF local, su identidad/versión, enlace de obtención, fecha, verificador y estado del permiso. Las referencias históricas del experimento se conservan para no alterar sus resultados; las diferencias entre la cita original y la edición realmente usada se explican en el README del Entregable 3.
